# P03 区际迁移 Markov：稳态 + 细致平衡检验 + 净流

## 这个项目在回答什么问题？

你把城市切成若干区域（或若干“状态”）。每天/每周都有人从区域 \(i\) 迁到区域 \(j\)。  
我们想回答三类问题：

1. **长期分布在哪里？**（稳态 \(\pi\)）
2. **长期看起来稳定时，人是不是还在动？**（净流 \(J_{ij}\)）
3. **这是不是“平衡稳态”？还是“被驱动的稳态”？**（细致平衡是否被打破）

这三问对应 M8 的核心区分：\(\pi\) 只回答“分布不变”，而 \(J\) 才暴露“环流/不可逆驱动”。

## 你将产出什么？

- **稳态分布**：\(\pi=\pi P\)（长期人口占比/驻留比例）
- **净流矩阵**：\(J_{ij}=\pi_iP_{ij}-\pi_jP_{ji}\)（哪条边上存在方向性）
- **细致平衡违反度量**：一个标量指标（越大越“非平衡”）

本项目配套了最小可复用代码：`src/markov.py` 与自动测试：`tests/test_markov_project.py`。

## 如何运行与验收

### 1) Notebook（项目主线）

打开并从头运行：

- `notebooks/P03_markov_migration.ipynb`

你应该能在 notebook 里完成：

- 用一个合成迁移矩阵构造行随机转移矩阵 \(P\)
- 计算稳态 \(\pi\) 并验证 \(\pi P\approx \pi\)
- 计算净流 \(J\) 并判断是否存在环流

### 2) pytest（最小正确性门槛）

运行：

- `python -m pytest projects/p03_markov_migration/tests/test_markov_project.py -q`

这个测试覆盖两种“必须过关”的情形：

- 对称构造（无驱动）应当满足细致平衡：净流 \(\approx 0\)
- 三态环（强驱动）应当出现非零净流：细致平衡被打破

## 目录结构

- `notebooks/`：主线实验（从数据/合成例子到 \(\pi\)、\(J\)）
- `src/`：可复用函数（稳态、净流、细致平衡违反度量）
- `tests/`：最小可验证门槛（保证你写的 \(P,\pi,J\) 口径一致）
