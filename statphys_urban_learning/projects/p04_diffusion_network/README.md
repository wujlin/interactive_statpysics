# P04 网络扩散（最小版）：从主方程到“扩散热图”

## 这个项目在回答什么问题？

在 M8 里我们已经有了“时间维度”的最小语言：如果状态之间以 Markov 规则跳转，那么分布会按主方程演化。

这个项目把问题压到最小、也最可视化的形式：

- 我从一个点出发（初始分布 $p_0$ 是一个脉冲）
- 每一步都按同一条转移规则扩散（转移矩阵 $P$）
- **分布 $p_t$ 会以什么速度摊开？什么时候“看起来已经稳定”？**

这对应城市里的一个直观问题：从某个出发点出发，随机游走式的“到达可能性”如何在路网/区际网络上扩散——这就是可达性（Accessibility）的一种最小基线模型。

## 先看现象：扩散热图（网页内交互）

下面的交互只做一件事：每一步执行一次

$$p_{t+1}=p_t P$$

你点击任意格点作为起点，就能看到“概率墨水”如何在网络上扩散并趋向稳态。

<InteractiveConcept type="diffusion-heatmap" />

你在这个交互里需要读出的三个要点：

1. **扩散不是轨迹**：单条随机游走轨迹是随机的，但 $p_t$ 的演化是确定的（主方程描述的是“所有轨迹的统计平均”）。
2. **稳态不等于停止**：这里的稳态是“分布不再变化”；是否存在净流/环流，要回到 M8 的净流判据去检验。
3. **弛豫时间是一个新问题**：同样的稳态分布 $\pi$，收敛速度可以完全不同（这将连接到 M8 的“弛豫时间/谱隙”的讨论）。

## 你将产出什么？

- `src/diffusion.py`：最小可复用函数（构造网格随机游走的 $P$、推进 $p_{t+1}=p_tP$）
- `tests/test_diffusion_project.py`：最小正确性门槛（行随机性、均匀分布的平稳性、扩散后“更均匀”）
- `notebooks/`：作为复现与误差分析的辅助（不是主入口）

## 如何验收（pytest）

运行：

- `python -m pytest projects/p04_diffusion_network/tests/test_diffusion_project.py -q`

通过标准（最小版）：

- 构造出的 $P$ 行和为 1（概率守恒）
- 在周期网格上，均匀分布是平稳分布（$uP=u$）
- 从脉冲初态出发，若干步后 $p_t$ 的最大/最小差距明显缩小（扩散在发生）

## 进阶方向（暂不强求）

如果你想把“多快扩散”变成一个可计算、可解释的数量，这会自然走到谱观点：

- 第二大特征值/谱隙 $\Rightarrow$ 混合时间（弛豫时间尺度）
- Laplacian 与 Fiedler 向量 $\Rightarrow$ 瓶颈与社区结构

这些属于 P04 的下一阶段，不是最小闭环的硬要求。
